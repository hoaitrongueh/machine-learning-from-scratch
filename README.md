# Machine Learning from Scratch

A collection of Python scripts I write while learning machine learning fundamentals.

I started with basic gradient descent and regression using Python loops, then moved to NumPy. This repository keeps those exercises together so I can revisit earlier work and track my progress.

## Topics so far

* Gradient descent
* Linear regression
* Binary logistic regression
* NumPy vectorization
* Feature standardization
* Train, validation, and test splits
* Loss and accuracy evaluation

I implement the calculations myself to understand how they work. NumPy handles array operations.

## About the code

Most files are standalone exercises. Some cover similar ideas at different stages of my learning, so there is intentional repetition.

The code is still developing and may contain mistakes or things I can improve. Current examples use small synthetic datasets to practice the calculations and workflow. High accuracy on these examples does not demonstrate performance on real-world data.

## Running an exercise

Install Python 3 and NumPy:

```bash
python -m pip install numpy
```

From the repository folder, run the script you want to explore. For example:

```bash
python logistic_regression_train_val_test.py
```
